# Roadmap

## Fase 1 — Fundação

- Validar o schema PostgreSQL.
- Criar Views de apoio.
- Consolidar dados fictícios.

## Fase 2 — Aplicação

- Ligar dashboard à API.
- Implementar CRUD principal.
- Implementar compras, stock, receitas e vendas.

## Fase 3 — Qualidade

- Testes automatizados.
- Autenticação e perfis.
- Auditoria e backups.

## Fase 4 — Produto

- Aplicação Electron para Windows.
- Configuração independente por cliente.
- Instalador, licenciamento, suporte e demonstração comercial.
